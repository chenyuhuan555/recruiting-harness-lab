# 招聘 AI 故障演练台

用同一份虚构简历、两个岗位和可重复注入的故障，展示招聘草稿怎样被拦在流转前。演练仅在浏览器运行，不调用模型，不处理真实简历。

在项目目录运行 `python -m http.server 4399 --bind 127.0.0.1 --directory dist`，打开 `http://127.0.0.1:4399/`。运行 `node --test` 执行自动检查。

| 场景 | 如何复现 | 预期结果 |
| --- | --- | --- |
| 正常基线 | 任意岗位，选「正常基线」 | 草稿有支持它的原文，进入待人工复核 |
| 夸大经历 | 选「夸大经历」 | 逐字引用通过，但参与或协作不能证明独立负责，暂停流转 |
| 串用岗位 | 切换岗位，选「串用岗位」 | 模拟另一个岗位的草稿晚到，在检查证据前隔离 |
| 模型无响应 | 选「模型无响应」 | 保留当前岗位与原文，交人工接手 |

`dist/guard.mjs` 中的 `simulate` 只生成测试草稿，`inspect` 独立执行岗位一致性、原文定位和支持关系核验。支持关系用人工标注的样本标签及固定结论验证，不声称能自动理解任意简历。实际系统还需用可信请求上下文绑定岗位和版本，对无法确定的证据安排顾问复核。
